מועמד לבדיקה ידנית בחתימת NEXO המקורית ובשרשרת החתימה הקיימת. התקנה ושדרוג בטלפון אמיתי טרם נבדקו.
רכישות Play והתראות מרחוק עדיין אינן מופעלות. לא פורסם עדכון ב־Google Play ולא שונה פיד עדכונים אוטומטיים.
